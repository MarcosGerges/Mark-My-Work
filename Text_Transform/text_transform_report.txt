USER REQUESTS
1. Read a string from the user and apply these transformations in sequence: invert the case of letters, swap the first and last letters, then insert a comma after the fifth character. If the string has no fifth character, put the comma at the end. Prompt for another input when the string contains one or fewer letters, including when the user enters only a space.
2. Refactor the implementation so that the transformations are split into smaller functions, each responsible for one aspect.
3. Export the transformation-related discussion and test information to this report.

IMPLEMENTATION SUMMARY
Text_transform.py uses separate helpers for each operation:
- invert_case(text) changes letter case with str.swapcase().
- swap_first_last_letters(text) finds alphabetic-character positions, swaps the first and last letters, and leaves intervening spaces and punctuation in place.
- add_comma(text) inserts a comma after character five when the text is longer than five characters; otherwise it appends the comma.
- transform_text(text) runs the three transformations in order.
- get_valid_input() continues prompting until the input contains at least two alphabetic characters.

The program prints the result returned by transform_text(get_valid_input()). The pipeline order is case inversion, letter swap, then comma insertion.
